# Automatic encoded-film Critic review

Every `renderProject` export now invokes Studio Critic after the MP4 is encoded, stream-verified and hash-bound. CLI `render`, `create` (including each repair pass), and the Studio **Render preview** button share this path. No per-run config, extra review command or manual upload is required on a configured host.

The render receipt contains `critic`; creation runs retain it on their render attempt and result. A `.mp4.critic.json` sidecar retains the current report pointer and prior attempt history. The Studio result shows **Open automatic Critic report**, and shows analysis progress while the encoded file is being reviewed. JSON consumers receive status, exact video/source binding, integrity, report path/link, supported checks and candidate counts.

The adapter reads the portable project's source recording, `audio.offset`, timed words/phrases and intake `originalLyrics`/`originalTiming`/`originalBeats`. Section render offsets map into recording time without inventing acoustic word onsets. Canonical lyrics remain the original source bytes. No canonical source means explicitly unavailable lyric authority; timing text is never promoted to canonical text. An optional `critic.canonicalLyrics` is a source path for projects with an existing authority outside intake. Optional `critic.intentional` intervals use project seconds and retain measurements rather than disabling them.

The host-level runtime defaults to `/Volumes/Code/studio-critic`; its private `integration-settings.json` supplies `python` and `viewerUrl`. Environment overrides are `ARK_CRITIC_ROOT`, `ARK_CRITIC_PYTHON`, `ARK_CRITIC_URL`, and `ARK_CRITIC_ARCHIVE`. Overrides are for deployment/testing, not routine operation. Hosts without the runtime return an explicit unavailable review; a successful encode is never presented as a successful Critic check.

Before and after analysis the adapter verifies exact video bytes and the renderer/project revision recorded at encoding. Critic verifies canonical/source/evidence bytes. Stale files, missing mounts, source changes, failed workers or unsupported benchmark revisions stay visible. Only benchmark-supported technical checks are exposed as technical candidates. OCR remains advisory; no candidate-free result means an aesthetic pass. Existing Ark audio/visual review, repair and approval gates remain authoritative. Critic neither changes Music Studio approvals/releases nor renders or publishes media.
