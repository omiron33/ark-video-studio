# Motion reference library

Start with [the workflow](../../docs/MOTION_REFERENCES.md), or run `node engine/cli.mjs serve-references` from the repository root to browse the image sequences.

This initial collection contains 17 inspected references: 12 from four finished internal videos and 5 from the supplied [Phil Trubey post](https://x.com/ptrubey/status/2104062055712260161), which shares [John Knopf’s original post](https://x.com/johnknopf/status/2103698854399099057). The collection includes 102 source frames and 17 timestamped contact sheets. No source MP4s are copied here.

- `cards/`: machine-searchable descriptions, source provenance and observation notes.
- `images/`: actual sampled visual evidence, grouped by stable reference ID.
- `sources/`: source attribution and retrieval details for external material.

A search score measures relevance, not artistic quality. “Observed” means that the card’s sampled images were inspected; it does not certify full motion or audio sync. “Liked” on the outside references describes Shane’s interest in the source video, not approval of each excerpt. Internal examples retain unknown user preference and include explicit limitations. One foreground-occlusion card is a cautionary reference.

Each reference documents a transferable principle and ways to adapt it. Retrieve a few images into the current scene’s context, then create new work from the song’s own meaning and timing.
